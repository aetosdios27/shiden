# Shiden Roadmap

## Phase 1 — Wire
TCP server, RESP2 parser and encoder, command dispatch.

## Phase 2 — Memory
Strings, keyspace, expiration, core command semantics.

## Phase 3 — Structures
Lists, hashes, sets, sorted sets.

## Phase 4 — Pressure
Concurrency, pipelining, memory behavior, eviction, benchmarks.

## Phase 5 — Semantics
Transactions, blocking behavior, compatibility edges.

## Phase 6 — Hardening
Fuzzing, profiling, compatibility testing, observability.
